# Generated model data

All CSV files are generated by `python examples/build_figures.py --output .` from the equations and parameter values in [the model document](../docs/model.md). There is no measurement import, smoothing, normalization to an experiment, or fitted calibration. Original generated tables are covered by the repository MIT license.

| File | Calculation and conditions | Rows |
|---|---|---:|
| `carrier_regimes.csv` | Si:P, donors 10¹⁵ cm⁻³, no acceptors, 40–1000 K; Fermi–Dirac populations and analytical Boltzmann intrinsic density | 180 |
| `ionization_errors.csv` | Si:P, no acceptors; 32 donor densities from 10¹² to 10¹⁷ cm⁻³ and 36 temperatures from 40 to 400 K | 1,152 |
| `statistics_errors.csv` | Ideal parabolic-band carrier statistics at fixed reduced Fermi energy, from −10 to 4 | 240 |
| `degeneracy_shift.csv` | 300 K, complete ionization, no acceptors; 110 donor densities from 10¹⁵ to 10²⁰ cm⁻³ | 110 |

Columns ending `_K`, `_eV`, `_cm3`, and `_percent` use kelvin, electronvolts, inverse cubic centimeters and percent respectively. Fractions, ratios, and reduced Fermi energies are dimensionless. Fermi levels are measured from the valence edge. `result_type` labels the numerical tables; `intrinsic_boltzmann_analytical_cm3` explicitly identifies the analytical column in the carrier-regime table.

The complete-ionization error is 100 × (complete-model electron density / incomplete-model electron density − 1). Both use Fermi–Dirac carrier statistics. The statistics error is 100 × (exp(η) / F₁/₂(η) − 1), evaluated at fixed η, not at fixed doping.

High-temperature and high-doping extrapolations are labeled in `scope_notes` where applicable and shaded in the figures. The carrier-regime plot shows only concentrations above 10¹² cm⁻³ for readability; the CSV retains the full calculated values. Logarithmic color limits in the error map have explicit extension indicators. Contour positions interpolate the finite sampling grid; they are not extra high-resolution calculations.

Published scalar material parameters are cited reference inputs, not measurements made by this project. No third-party data license is implied by the code license.
